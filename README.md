## ⚡ What is CloneMeAI?

CloneMeAI is a **portable, local-first automation suite** designed for high-volume AI content creators. It eliminates the need for complex Airtable scripts or Python installations. 

We combine the power of **Google Gemini / xAI Grok** (Reasoning) with **Wavespeed / Fal.ai** (Generation) into a single, drag-and-drop interface.

### 💎 Key Features

*   **Identity Matrix:** Upload Face & Body references once, apply them to infinite generations.
*   **Smart Queue:** Drag & Drop batch processing with individual aspect ratio controls.
*   **Dual Pipeline:** Dedicated workflows for **Standard (SFW)** and **Unfiltered (NSFW)** content generation.
*   **Auto-Save System:** Generated assets are instantly saved to your local Pictures folder. No data loss.
*   **Zero-Install:** Runs as a portable executable on Windows and Mac. No installation required.

## 🚀 Getting Started

1.  **Download:** Get the latest version from our [Official Page](https://gumroad.com/l/YOUR_LINK).
2.  **Run:** 
    *   **Windows:** Double-click `CloneMeAi.exe`.
    *   **Mac:** Open `CloneMeAi.dmg` and drag to Applications (or run directly).
3.  **Configure:** Click the **Settings (Gear)** icon to enter your API Keys.
4.  **Generate:** Drag source images into the queue and click **Start Generation**.

---

## 🔒 Privacy & Security

CloneMeAI follows a **Local-First** philosophy.
*   **Your Keys:** API keys are stored encrypted on your local machine. They are never sent to our servers.
*   **Your Images:** All generation happens via direct API calls from your computer to the provider. We do not store or view your generations.
*   **Your Data:** Trial usage data is stored locally.
